Notificação

O sensor MQ-6 detecta a presença de gás, enviando os dados para o ESP32. O microcontrolador processa as informações e, em caso de vazamento, aciona o LED e o buzzer para alertar os moradores. Além disso, uma notificação é enviada para o celular do usuário, garantindo segurança mesmo quando não há ninguém na cozinha.
